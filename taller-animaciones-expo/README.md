# Taller de Animaciones con React Native Reanimated + Expo

App única con Drawer Navigation que integra 6 ejercicios de animación y gestos:

1. Drag & Drop con rotación
2. Animación de carga (spinner infinito + barra de progreso)
3. Gestos multitouch (zoom, mover y rotar imagen)
4. Animación Bounce
5. Carrusel animado
6. Acelerómetro (shake)

## Instalación
```bash
npm install
npx expo install --fix
npx expo start
# Verificar tipos (opcional)
npx tsc --noEmit
```
Escanea el QR con Expo Go (en un dispositivo físico para probar el acelerómetro).

## Tecnologías
TypeScript, Expo, react-native-reanimated, react-native-gesture-handler, expo-sensors, React Navigation (Drawer).
